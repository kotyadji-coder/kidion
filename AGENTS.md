# Правила Codex Для Этого Проекта

Этот проект подключен к общему Безопасному режиму Codex.

Общие правила находятся здесь:

```text
/root/ai-harness/HARNESS.md
```

Перед любыми изменениями:

1. Прочитай `/root/ai-harness/HARNESS.md`.
2. Прочитай `PROJECT.md`.
3. Прочитай `HARNESS.yaml`.
4. Проверь `git status`.
5. Сначала составь план.
6. Только потом меняй код.

Запрещено без отдельного разрешения:

- выкладывать живой проект;
- пушить напрямую в `main` или `master`;
- менять `.env`, токены, ключи, пароли;
- удалять базы, uploads, media, backups, Docker volumes;
- делать лишний рефакторинг.

Живую выкладку можно делать только после команды владельца отдельным сообщением или отдельной строкой:

```text
деплой
```

После изменений:

1. Запусти `./scripts/check.sh`, если он есть.
2. Запусти `./scripts/local-verify.sh`, если он есть.
3. Если это сайт, запусти `./scripts/browser-check.sh`, если он есть.
4. Проверь `git diff`.
5. Дай отчет простым языком.
6. Обязательно напиши: `Проверено. Готово к выкладке. Живой проект не тронут.` или `Нельзя выкладывать: есть проблемы`.
