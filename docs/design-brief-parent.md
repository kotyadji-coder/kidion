# Kidion — ТЗ для AI-дизайнера: интерфейсы для родителей

## О проекте

**kidion.ru** — персонализированная образовательная платформа для детей 6-10 лет. Родители создают профиль ребёнка, ИИ генерирует уникальную вселенную и персонажа, затем создаёт интерактивные уроки по школьной программе внутри этой вселенной. Дети проходят уроки, зарабатывают звёзды и тратят их на кастомизацию персонажа.

**Целевая аудитория родительского интерфейса:** мамы и папы детей 6-10 лет (1-4 класс). Не технические пользователи. Преимущественно мобильный трафик.

**Текущий стек фронтенда:** Jinja2 шаблоны + vanilla JS + CSS (без фреймворков). Шрифт — системный (Inter/Plus Jakarta Sans на лендинге, стандартный в кабинете).

**Секция FAQ** (аккордеон):

## Страница 2: Регистрация / Вход (/register, /login)

**Цель:** Максимально простая авторизация.

- Логотип
- Заголовок: «Вход в аккаунт»

## Страница 4: Создание ребёнка (/children/new)

**URL:** `/children/new`
**Цель:** Пошаговый мастер создания профиля. Двухшаговый визард.

### Индикатор прогресса:
- 2 круглых шага (1 → 2) с линией между ними
- Активный шаг: залитый основным цветом
- Пройденный шаг: залитый зелёным

### Шаг 1: «Расскажите о ребёнке»
- Подзаголовок: «Эти данные нужны, чтобы подобрать правильную школьную программу.»
- Поля:
  - Имя ребёнка (текст, плейсхолдер: «Андрей»)
  - Пол (select: Мальчик/Девочка) + Класс (select: 1-4) — в одну строку
  - Дата рождения (date picker, опционально)
  - ПИН-код, 4 цифры (password input, numeric keyboard)
    - Подсказка: «С помощью этого кода ребёнок будет сам входить в свой кабинет»
- Кнопки: «Отмена» (ведёт на дашборд) + «Далее: Создать вселенную»

### Шаг 2: «Создаём персональную вселенную»
- Подзаголовок: «ИИ проанализирует ваши ответы и создаст уникальный мир, героя и магазин наград.»
- Подсказка (градиентный блок): «Чем подробнее вы заполните — тем интереснее будет мир! Можно просто нажимать на теги ниже.»
- 5 вопросов-полей:
  1. Любимые герои и персонажи (текст, плейсхолдер: «Гарри Поттер, Наруто, Фиксики...»)
  2. Любимые животные (текст + теги-кнопки: Динозавры, Котики, Единороги, Собаки, Драконы)
  3. Хобби и увлечения (текст, плейсхолдер: «Рисование, футбол, лего...»)
  4. В каком мире хотел бы оказаться? (текст + теги: Космос, Подводный мир, Магическая школа, Киберпанк, Средневековье)
  5. Что больше всего интересует в учёбе? (текст)
- Кнопки: «Назад» + «Создать профиль (Бесплатно)»
- При нажатии кнопка меняет текст на «Создаём вселенную...» и блокируется

**Теги-кнопки:** Маленькие пилюли с «+» справа. Клик добавляет текст в поле ввода через запятую. Стиль: фон — светлый основной цвет, текст — основной цвет.

## Страница 5: Профиль ребёнка (/children/{id})

**URL:** `/children/{id}`
**Цель:** Центр управления ребёнком. Предметы, свободные уроки, вселенная.

### Верхняя навигация:
- Ссылка «← Назад к детям» (на дашборд)

### Двухколоночный layout:

**Левая колонка — Сайдбар (260px, sticky):**
- Аватар персонажа (80px, круглый) или эмодзи
- Имя ребёнка
- «X класс»
- Увлечения (если заполнены)
- Разделитель
- Статистика: Баланс ⭐, Ударный режим 🔥
- Разделитель
- Кнопки:
  - «Кабинет ребёнка» (основная, ведёт в /kid/login)
  - «История уроков» (ghost)

**Правая колонка — Контент:**

**Секция 1: Программа обучения**
- Иконка 📚, заголовок, подзаголовок: «Выберите предмет, чтобы начать»
- Сетка 3 карточки предметов:
  - Математика (📐), Русский язык (📝), Окруж. мир (🌍, неактивный)
  - Каждая карточка: иконка + название + прогресс (X/Y уроков)
  - Hover: приподнимается, рамка акцентным цветом
  - Неактивная: полупрозрачная, pointer-events: none

**Секция 2: Свободные уроки**
- Иконка 🎨, заголовок, подзаголовок: «Любая тема — для любопытства и развлечения»
- Форма в одну строку:
  - Текстовое поле (плейсхолдер: «Например: Почему вымерли динозавры»)
  - Select предмета (Окруж. мир / Математика / Русский язык / Другое)
  - Кнопка: «Создать урок (20 💎)»
- Блок статуса генерации (скрыт по умолчанию)
- Список созданных свободных уроков:
  - Каждый элемент: название + звёзды (★★★ или статус «Готов»/«Генерация...»)
- Пояснение внизу: «Звёздочки — это личная награда ребенка. Он тратит их на одежду для персонажа. Кристаллы ребенок не видит.»

**Секция 3: Вселенная героя**
- Иконка 🌌, заголовок, подзаголовок: «Уникальный мир, созданный ИИ»
- Горизонтальный блок:
  - Изображение персонажа (100x100, скруглённые углы)
  - Текст описания вселенной (или «Вселенная создаётся... Обновите страницу через пару минут.»)
- Блок «Пересоздать персонажа и магазин наград»:
  - Пояснение: что произойдёт (удалится персонаж, магазин, купленные вещи)
  - Кнопка: «Пересоздать вселенную» (outline, акцентный цвет)

**Модальное окно «Пересоздать вселенную»:**
- Предупреждение (красный фон): «Купленные предметы будут удалены. Звёзды не вернутся.»
- 5 полей (как при создании): герои, животные, хобби, мир, учёба
- Кнопки: «Отмена» + «Пересоздать»

### Мобильная адаптация:
- Сайдбар уходит наверх (одна колонка)
- Сетка предметов: 2 колонки
- Форма свободных уроков: вертикальная

## Страница 6: Предмет (/children/{id}/subject/{subject})

**URL:** `/children/{id}/subject/math` (или russian)
**Цель:** Управление учебной программой по предмету. Генерация уроков.

### Хлебные крошки:
- Дашборд > {Имя ребёнка} > {Предмет}

### Информационный блок (сворачиваемый):
- Градиентный фон
- «Как здесь всё устроено?»
- Описание: нажмите «Создать уроки», нейросеть превратит тему в приключение
- 4 пункта: Сюжетная теория, Интерактив, Печатные квесты, Мотивация
- Подсказка: можно пройти тест-пропуск для знакомых тем
- Кнопка закрытия (×). После 5+ визитов сворачивается автоматически, показывается кнопка «Как здесь всё устроено?»

### Блок статистики (3 карточки в ряд):
- Пройдено уроков: X/Y
- Текущая тема: название
- Заработано звёзд: N ⭐

### Программа (список тем):
Вертикальный список карточек-тем (topic cards). Каждая тема = 5 уроков.

**Состояния темы:**
- Пройдена: зелёная полоска слева
- Активная: фиолетовая полоска слева
- Заблокирована: серая полоска, слегка прозрачная

**Карточка темы:**
- Заголовок (кликабельный, раскрывает/сворачивает): иконка + название + прогресс (X/5 уроков · Y ⭐)
- Кнопки в заголовке:
  - «Тест для пропуска» (ghost) — только для заблокированных тем
  - «Создать уроки (100 💎)» (primary) — если уроки не сгенерированы
- Шеврон (▼) — индикатор раскрытия

**Раскрытое содержимое темы (5 уроков):**
- Каждый урок: иконка статуса + название + звёзды
  - ✅ — пройден (+ количество звёзд)
  - ⏳ — генерируется (иконка вращается)
  - 🟡 — доступен
  - 🔒 — заблокирован
- Кликабельные уроки (готовые): подчёркнутые, фиолетовый цвет, открывают урок

**Прогресс-бар генерации:**
- Появляется внутри карточки темы при генерации
- Полоска с процентом + текст «Генерация: X/5»
- Анимация пульсации текста
- По завершении заменяется на:
  - Кнопка «✨ Перейти к урокам» (зелёная, жирная)
  - Кнопка «🖨 Рабочая тетрадь» (outline)

**Блок «Занятия на месяц»** (вставляется после 4-й заблокированной темы):
- Иконка 📅
- «Создайте сразу 4 темы (20 уроков) — этого хватит на месяц»
- Кнопка: «Создать уроки на месяц (400 💎)»
- Или состояние «✅ X уроков готовы!» + кнопки «Перейти к урокам» и «Рабочая тетрадь»

**Модальные окна:**
1. Подтверждение генерации темы: иконка 💎, стоимость, сколько останется кристаллов
2. Подтверждение теста-пропуска: иконка ⏭️, предупреждение позвать ребёнка
3. Генерация на месяц: иконка 📅, стоимость 400 💎

**Тест-пропуск (fullscreen overlay):**
- Полноэкранный оверлей (фиолетовый фон)
- Заголовок: «Тест: {название темы}»
- Iframe с тестом
- По завершении: экран «Тест завершён! Позови маму или папу» + кнопка «Продолжить»
- Результат (модалка): успех (🎉) или нужно повторить (📚)

## Страница 10: Урок (/kid/lesson/{id}) — контент

**URL:** Генерируемый HTML (не шаблон, отдельная standalone страница)
**Контекст:** Открывается и в iframe внутри детского кабинета, и напрямую по ссылке из родительского кабинета.

### Визуальный стиль:
- Фоновое изображение (генерируется ИИ, уникальное для темы)
- Полупрозрачный градиентный оверлей

### Структура:

**Шапка (glass card):**
- Бейдж: «Урок · Kidion»
- Заголовок урока (крупный, жирный)

**Теоретические блоки** (glass cards, появляются с анимацией scroll-in):
- Каждый блок: эмодзи-иконка (54x54, в стеклянном квадрате) + текст
- Анимация: fade-in + slide-up при скролле

**Разделитель с картинкой** (мобильная версия):
- Изображение урока
- Градиентный текст поверх: «Теперь мы всё знаем! Пора выполнять миссии!»

**Секция заданий (5 заданий):**
- Заголовок: «Задания» (бейдж-пилюля на фиолетовом фоне)

**Типы заданий:**

1. **Quiz** (выбор одного ответа):
   - Номер + бейдж «Выбери ответ» (фиолетовый)
   - Вопрос
   - Кнопки-пилюли с вариантами
   - Обратная связь: зелёная/красная подложка

2. **Multiple Choice** (несколько ответов):
   - Бейдж «Выбери несколько верных ответов»
   - Кнопки с toggle-выделением + кнопка «Проверить»

3. **Drag and Drop** (перетаскивание):
   - Бейдж «Перетащи»
   - Подсказка: «перетащи слово из банка слов в нужное место»

   - Зоны сброса (пунктирная рамка)

4. **Fill in the Blank** (ввод ответа):
   - Бейдж «Заполни пропуск»
   - Текстовое поле (пилюля) + кнопка «Проверить»

5. **Ordering** (расставить по порядку):
   - Бейдж «Расставь по порядку»
   - Перетаскиваемый список + кнопка «Проверить порядок»

**Баннер завершения (glass card):**
- Иконка 🏆
- «Все задания выполнены!»
- Счёт: «X из Y заданий решено верно с первого раза!»
- Анимация появления

**Кнопки внизу:**
- «🖨 Распечатать» (вторичная, стеклянная)
- «✨ Создать урок» (основная, фиолетовая)

## Общие требования к дизайну

### Стиль:
- **Чистый, современный, дружелюбный.** Родитель должен чувствовать доверие и профессионализм.
- **Не перегруженный.** Много воздуха, крупные кликабельные зоны.
- **Mobile-first.** Основной трафик — мобильный.

### Цветовая палитра (текущая):
- Primary (основной): #6C5CE7 (фиолетовый)
- Accent: коралловый/оранжевый для CTA
- Success: #00B894 / #10B981 (зелёный)
- Error: #D63031 (красный)
- Background: #F8F9FA (светло-серый)
- Surface: #FFFFFF
- Text: #2D3436 (тёмно-серый)
- Text muted: #636E72

### Типографика:
- Лендинг: Plus Jakarta Sans (800, 700, 600, 500, 400)
- Кабинет: системный шрифт или Inter/Nunito

### Компоненты:
- Кнопки: скруглённые (border-radius 8-12px), с тенью для primary
- Карточки: скруглённые углы (12-16px), лёгкая тень
- Инпуты: 1.5px рамка, скруглённые, фокус — фиолетовая рамка + лёгкая тень
- Модалки: затемнённый оверлей + центрированная карточка с анимацией
- Бейджи/теги: пилюли (border-radius: 999px)

### Адаптивность:
- Мобильный (< 480px): одна колонка, увеличенные тач-зоны
- Планшет (480-768px): 2 колонки где возможно
- Десктоп (> 768px): полный layout

### Важные UX-моменты:
- Кнопки блокируются при отправке (disabled + текст «Загрузка...»)
- Прогресс-бары для длительных операций (генерация уроков ~30-60 сек)
- Inline-ошибки, не alert()
- Копирование ссылки: кнопка меняет текст на «Скопировано!» на 2 сек
