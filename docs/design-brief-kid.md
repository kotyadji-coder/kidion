# ТЗ на редизайн детского интерфейса Kidion

## Контекст

Kidion (kidion.ru) — образовательная платформа для детей 6–10 лет. Ребёнок заходит через детский интерфейс (вход по PIN-коду), проходит уроки по предметам, зарабатывает звёзды, тратит их в магазине персонажа. Уроки генерирует AI — каждый урок персонализирован под вселенную и интересы ребёнка.

**Целевая аудитория:** дети 6–10 лет (1–4 класс). Пользуются со смартфона родителя или планшета. Преимущественно мобильный трафик.

**Стек:** HTML/CSS/JS (без фреймворков). Шаблоны Jinja2. Дизайнер готовит HTML/CSS, мы вставляем в шаблоны.

## Страница 1: Главная (/kid/home)

### Назначение
Центральная страница ребёнка после входа. Отсюда он переходит к урокам, магазину персонажа и чату.

### Блоки и их смысл

#### 1. Шапка (sticky)
- **Лого** kidion.ru (кликабельный, ведёт на /kid/home)
- **Серия (streak)** — сколько дней подряд ребёнок занимается (число + иконка огня)
- **Звёзды** — баланс звёзд ребёнка (число + иконка звезды). Клик → страница персонажа
- **Аватар** — круглая картинка персонажа ребёнка (AI-генерированная PNG). Клик → страница персонажа

#### 2. Герой-секция
- **Персонаж** — большая круглая картинка AI-персонажа ребёнка (у каждого ребёнка свой уникальный персонаж). Клик → страница персонажа (/kid/character)
- **Речевой пузырь** — «Привет, {имя}! Продолжим приключение?» (текст приветствия от персонажа)
- **Кнопка «В ПУТЬ!»** — большая основная CTA, ведёт к первому активному предмету. Под кнопкой мелким текстом — название предмета

#### 3. Предметы (порталы)
Заголовок: «Миры» + подсказка «Выбери, куда отправиться»

Карточки предметов (сейчас 4 + свободные уроки):
- **Математика** 🚀 — оранжевый
- **Русский язык** 📖 — голубой
- **Английский язык** 🌍 — зелёный
- **Окружающий мир** 🧩 — фиолетовый
- **Свободные уроки** 🎨 — розовый (появляется, если есть)

Каждая карточка:
- Круглая иконка с эмоджи
- Название предмета
- Прогресс-бар (% пройденных уроков) — если ребёнок записан
- Или надпись «Скоро» — если не записан
- Бейдж «Продолжить» на активном предмете

Клик по карточке → карта уроков предмета (/kid/subject/{subject})

#### 4. Нижние карточки
Две горизонтальные карточки:
- **Магазин** — «Тратить звёзды» → /kid/character (страница персонажа с магазином)
- **Чат с Киди** — AI-чат для детей → /spark/chat (отдельный интерфейс)

#### 5. Мобильная версия
- Приоритет мобайл (90% пользователей — с телефона)
- Персонаж уменьшается, сетка предметов — 2 колонки
- Нижние карточки — 2 колонки

### Что не нравится сейчас
- Выглядит «старомодно» — облачка на фоне, слишком простые карточки
- Хочется современный, яркий, но не перегруженный дизайн для детей
- Важно: не «для малышей» — дети 8–10 лет уже считают себя большими

### Референсы (по духу)
- Duolingo (яркость, геймификация, простота)
- Khan Academy Kids (мягкие цвета, дружелюбность)
- Toca Boca (игривость без инфантильности)

## Страница 2: Урок (/kid/lesson/{id})

### Назначение
Страница прохождения одного урока. Урок — это HTML-контент внутри iframe. Ребёнок читает объяснение, смотрит картинки, выполняет 5 интерактивных заданий.

### Блоки и их смысл

#### 1. Верхняя панель (topbar)
- **Кнопка «Назад»** (стрелка ←) → /kid/home
- **Предмет** — мелкий текст (например, «Математика»)
- **Название урока** — основной текст (например, «Дроби: что это и зачем?»)
- **Кнопка «Квест»** 🖨️ — ссылка на PDF рабочий лист для печати (есть не у всех уроков)

#### 2. Контент урока (iframe)
Занимает всю оставшуюся высоту экрана. Внутри iframe:
- Объяснение темы (текст + картинки, адаптированные под вселенную ребёнка)
- 5 интерактивных заданий (тесты, drag-and-drop, ввод ответа)
- Когда ребёнок выполняет все задания, iframe отправляет результат через postMessage

**Важно:** содержимое iframe дизайнер не трогает — оно генерируется AI. Дизайнер оформляет только обёртку вокруг iframe.

#### 3. Подвал
- Строка «Урок создан с помощью ИИ» + кнопка «Пожаловаться»
- Блок автосохранения результата (появляется после завершения всех заданий): «⏳ Сохраняю результат...»

#### 4. Состояние «Урок готовится»
Если контент ещё не сгенерирован — вместо iframe показываем спиннер и текст «Урок ещё готовится...»

### Что не нравится сейчас
- Страница слишком минималистичная — просто панелька сверху и iframe
- Нет ощущения «игры», ребёнок не чувствует прогресс во время урока
- Хочется, чтобы даже обёртка давала ощущение приключения

### Пожелания
- Ненавязчивая обёртка — не отвлекает от контента урока, но создаёт «рамку приключения»
- На мобильном — максимум места под iframe
- Можно добавить мотивационные элементы в обёртку (прогресс-бар «задание 3 из 5» — данные приходят из iframe через postMessage)

## Общие требования

- **Mobile-first** (90% трафика с мобильных)
- **Никаких внешних JS-фреймворков** — только vanilla JS + CSS
- Шрифты: можно предложить свои (сейчас Nunito + Baloo 2)
- Поддержка тёмной темы не нужна
- Картинки персонажей — PNG, генерируются AI, приходят по URL
- Дизайн должен хорошо смотреться и без картинки персонажа (placeholder — первая буква имени)
