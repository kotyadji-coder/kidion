# ТЗ на редизайн детского интерфейса Kidion

## Контекст

Kidion (kidion.ru) — образовательная платформа для детей 6–10 лет. Ребёнок заходит через детский интерфейс (вход по PIN-коду), проходит уроки по предметам, зарабатывает звёзды, тратит их в магазине персонажа. Уроки генерирует AI — каждый урок персонализирован под вселенную и интересы ребёнка.

**Целевая аудитория:** дети 6–10 лет (1–4 класс). Пользуются со смартфона родителя или планшета. Преимущественно мобильный трафик.

**Стек:** HTML/CSS/JS (без фреймворков). Шаблоны Jinja2.

---

## Страница 1: Главная (/kid/home)

### Назначение
Центральная страница ребёнка после входа. Отсюда он переходит к урокам, магазину персонажа и чату.

### Блоки и их смысл

#### 1. Шапка (sticky)
- **Лого** kidion.ru → /kid/home
- **Серия (streak)** — сколько дней подряд ребёнок занимается (число + иконка)
- **Звёзды** — баланс звёзд ребёнка (число + иконка). Клик → страница персонажа
- **Аватар** — круглая картинка персонажа ребёнка (AI-генерированная PNG). Клик → страница персонажа

#### 2. Герой-секция
- **Персонаж** — картинка AI-персонажа ребёнка (у каждого свой уникальный). Клик → страница персонажа (/kid/character)
- **Приветствие** — «Привет, {имя}! Продолжим приключение?» (текст от персонажа)
- **Кнопка «В ПУТЬ!»** — основная CTA, ведёт к первому активному предмету. Под кнопкой — название предмета

#### 3. Предметы
Заголовок: «Миры» + подсказка «Выбери, куда отправиться»

Карточки предметов (4 + свободные уроки):
- Математика, Русский язык, Английский язык, Окружающий мир, Свободные уроки (появляется, если есть)

Каждая карточка содержит:
- Иконка предмета
- Название
- Прогресс (% пройденных уроков) — если ребёнок записан
- Или надпись «Скоро» — если ещё не записан
- Метка «Продолжить» на активном предмете

Клик → карта уроков предмета (/kid/subject/{subject})

#### 4. Нижние карточки
- **Магазин** — «Тратить звёзды» → /kid/character
- **Чат с Киди** — AI-чат для детей → /spark/chat

### Что не нравится сейчас
- Выглядит устаревшим
- Хочется современный, яркий, но не перегруженный дизайн
- Не «для малышей» — дети 8–10 лет уже считают себя большими

## Страница 2: Урок (/kid/lesson/{id})

### Назначение
Страница прохождения одного урока. Урок — HTML-контент внутри iframe. Ребёнок читает объяснение, смотрит картинки, выполняет 5 интерактивных заданий.

### Блоки и их смысл

#### 1. Верхняя панель
- **Назад** (←) → /kid/home
- **Предмет** — мелкий текст (например, «Математика»)
- **Название урока** (например, «Дроби: что это и зачем?»)
- **Кнопка «Квест»** — ссылка на PDF рабочий лист для печати (не у всех уроков)

#### 2. Контент урока (iframe)
Занимает всю оставшуюся высоту экрана. Содержимое генерируется AI — дизайнер его не трогает, оформляет только обёртку вокруг iframe.

Внутри iframe: объяснение темы + 5 интерактивных заданий. По завершении iframe отправляет результат через postMessage.

#### 3. Подвал
- «Урок создан с помощью ИИ» + кнопка «Пожаловаться»
- Статус автосохранения (появляется после завершения заданий)

#### 4. Состояние «Урок готовится»
Если контент ещё не сгенерирован — спиннер и текст «Урок ещё готовится...»

### Что не нравится сейчас
- Слишком минималистично — просто панелька сверху и голый iframe
- Нет ощущения «игры», ребёнок не чувствует прогресс
- Хочется ненавязчивую обёртку, которая создаёт ощущение приключения, но не отвлекает от контента

### Пожелания
- На мобильном — максимум места под iframe
- Можно добавить прогресс-бар «задание 3 из 5» (данные приходят из iframe через postMessage)

## Общие требования

- **Mobile-first** (90% трафика с мобильных)
- **Никаких внешних JS-фреймворков** — только vanilla JS + CSS
- Шрифты — на усмотрение дизайнера
- Тёмная тема не нужна
- Картинки персонажей — PNG по URL (AI-генерированные)
- Дизайн должен хорошо смотреться и без картинки персонажа (placeholder — первая буква имени)
