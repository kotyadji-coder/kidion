# Spark Chat — ТЗ для AI-дизайнера

## О продукте

**chat.kidion.ru** — безопасный AI-чат для детей 6-10 лет. Отдельный продукт на поддомене kidion.ru, со своим лендингом и интерфейсом. Работает на том же бэкенде, что и kidion.ru (общие пользователи, оплата, подписки).

**Персонаж по умолчанию:** Спарк — дружелюбный огонёк в очках и фиолетовой мантии. Помимо Спарка доступны другие персонажи (подробнее ниже).

**Целевая аудитория:**
- **Дети 6-10 лет** — основные пользователи чата
- **Родители** — покупают подписку, настраивают, смотрят отчёты

**Платформа:** мобильный браузер (приоритет), десктоп — вторичен. Никаких нативных приложений.

**Стек фронтенда:** Jinja2 шаблоны + vanilla JS + CSS. Шрифт: Nunito (основной), Baloo 2 (заголовки, имена персонажей).

## Навигация и структура

### Для ребёнка (после входа)

**Верхняя панель (header):**
- Кнопка «Назад» (на домашнюю kidion, если пришёл оттуда, или на лендинг chat.kidion.ru)
- Аватар + имя текущего персонажа + статус «онлайн»
- Кнопка «Новый разговор» (сброс истории)

**Нижняя панель (mobile tab bar):**
- Чат (текущий разговор)
- Персонажи (выбор собеседника)
- Домой (возврат на kidion.ru/kid/home)

### Для родителя

Управление чатом интегрировано в родительский кабинет kidion.ru:
- Страница подписки на `/buy`
- Раздел «Отчёты по чату» на странице ребёнка

## Страница 1: Лендинг (chat.kidion.ru)

**URL:** `chat.kidion.ru` (для неавторизованных и как промо-страница)
**Цель:** Объяснить продукт, показать безопасность, конвертировать в регистрацию.

### Навбар лендинга:
- Логотип: иконка Спарка + «Spark Chat» (или «Спарк»)
- Навигация: Возможности, Безопасность, Тарифы
- Кнопки: «Войти», «Попробовать бесплатно» (CTA)

### Hero-секция:
- Заголовок: «Умный друг для вашего ребёнка»
- Подзаголовок: «Безопасный AI-помощник, который объяснит домашку, расскажет историю и поддержит любопытство. Для детей 6-10 лет.»
- CTA: «Попробовать бесплатно — 5 сообщений в день»
- Справа: макет экрана чата с примером диалога (ребёнок спрашивает про динозавров, Спарк отвечает)

### Секция «Что умеет Спарк» (4 карточки):
1. **Помощь с уроками** — объяснит тему простыми словами, поможет разобраться с домашкой
2. **Интересные факты** — расскажет о космосе, динозаврах, океане — о чём угодно
3. **Истории и сказки** — придумает персональную сказку по запросу ребёнка
4. **Творчество** — нарисует картинку по описанию ребёнка (AI-генерация)

### Секция «Безопасность»:
- Заголовок: «Полная безопасность для детей»
- 4 пункта с иконками:
  - Строгие фильтры контента (без насилия, политики, взрослых тем)
  - Не запрашивает персональные данные (адрес, телефон, школу)
  - Ответы адаптированы для возраста 6-10 лет
  - Родитель видит отчёт о темах разговоров

### Секция «Персонажи» (3-4 карточки):
Показать доступных персонажей-собеседников:
1. **Спарк** — универсальный помощник (бесплатно, по умолчанию)
2. **Профессор Сова** — учитель, объясняет школьные темы подробно
3. **Капитан Сказка** — рассказчик, придумывает истории и приключения
4. **Друг Пикси** — ровесник, болтает на детские темы, делится «секретами»

Каждая карточка: аватар персонажа + имя + короткое описание + пример фразы.

### Секция «Тарифы»:
| | Бесплатно | Подписка |
|---|---|---|
| Сообщений в день | 5 | 50 |
| Персонажи | Только Спарк | Все 4 персонажа |
| Голосовые сообщения | — | Да |
| Картинки от AI | — | Да |
| Отчёт для родителей | — | Да |
| Цена | 0 руб. | 300 кристаллов/мес (~300 руб.) |

CTA: «Начать бесплатно»

### Футер:
- Текст: «Spark Chat — безопасный AI-чат для детей от Kidion»
- Ссылки: Условия, Политика конфиденциальности, kidion.ru

## Страница 2: Выбор персонажа (/characters)

**URL:** `/characters`
**Контекст:** Ребёнок авторизован. Выбирает, с кем поговорить.

### Структура:
- Заголовок: «С кем поговорим?»
- Сетка персонажей (2 колонки на мобильном, 4 на десктопе):

Каждая карточка персонажа:
- Аватар (круглый, крупный, 80-100px)
- Имя персонажа (жирный шрифт)
- Короткое описание (1 строка)
- Статус: «онлайн» (зелёная точка)
- Если персонаж платный и нет подписки: замочек + «Подписка»
- При клике: переход в чат с этим персонажем

### Визуальный стиль:
- Карточки с мягкой тенью, скруглённые углы (16px)
- Пастельные фоны карточек, разные для каждого персонажа:
  - Спарк: оранжевый (#FFF3E0)
  - Профессор Сова: синий (#E3F2FD)
  - Капитан Сказка: фиолетовый (#F3E5F5)
  - Друг Пикси: зелёный (#E8F5E9)

## Страница 3: Чат с персонажем (/chat или /chat/{character})

**URL:** `/chat` (Спарк по умолчанию) или `/chat/owl`, `/chat/captain`, `/chat/pixie`
**Контекст:** Основной экран — ребёнок общается с выбранным AI-персонажем.

### Шапка (header):
- Кнопка «Назад» (к выбору персонажей или домой)
- Аватар персонажа (круглый, 40px) + имя + «онлайн»
- Справа: кнопка «Новый разговор» (иконка обновления)

### Область сообщений:

**Пустое состояние (нет сообщений):**
- Крупный аватар персонажа (100px)
- Приветственная фраза от персонажа (уникальная для каждого):
  - Спарк: «Привет! Я Спарк! Спроси меня о чём угодно!»
  - Сова: «Добро пожаловать в класс! Какой предмет разберём?»
  - Капитан: «Ого, новый путешественник! Какую историю придумаем?»
  - Пикси: «Привет-привет! Что нового расскажешь?»
- Подсказки-кнопки (3-4 штуки, разные для каждого персонажа):
  - Спарк: «Интересный факт», «Помощь с уроками», «Придумай историю»
  - Сова: «Объясни тему», «Проверь мои знания», «Расскажи опыт»
  - Капитан: «Придумай сказку», «Продолжи историю», «Загадка»
  - Пикси: «Что нового?», «Расскажи шутку», «Давай играть»

**Сообщения:**
- Сообщения ребёнка: справа, зелёный фон (#22C55E), белый текст, скруглённые углы (16px, правый нижний — 6px)
- Сообщения персонажа: слева, светлый фон (#F8F6FF), тёмный текст, аватар персонажа рядом (30px)
- Каждое сообщение: текст + время (мелкий шрифт, серый)
- Поддержка markdown: **жирный**, *курсив*
- Картинки: отображаются в сообщении (max 200px), скруглённые углы
- Анимация появления: fade-in + slide-up

**Индикатор набора (typing):**
- Аватар персонажа + пузырь с тремя прыгающими точками

### Область ввода (input area):

- Счётчик сообщений: «Осталось X сообщений сегодня» (мелкий текст сверху)
- Поле ввода: rounded pill, placeholder «Напиши {имя персонажа}...»
- Кнопка микрофона (голосовой ввод) — слева от поля (подписка)
- Кнопка скрепки (прикрепить картинку) — справа от поля
- Кнопка отправки: круглая, цвет акцента персонажа, иконка стрелки
- Превью прикреплённого файла: мини-превью + кнопка удаления

**Голосовой ввод (по подписке):**
- При нажатии на микрофон: пульсирующий круг, запись
- «Говори, я слушаю!» — текст в центре
- Кнопка стоп → speech-to-text → текст в поле ввода
- Если нет подписки: тултип «Доступно по подписке»

### Нижняя панель (mobile tab bar):
- Чат (активный)
- Персонажи
- Домой (kidion.ru)

## Страница 5: Отчёт для родителя (в кабинете kidion.ru)

**URL:** `/children/{id}/chat-report` (в родительском интерфейсе kidion.ru)
**Контекст:** Родитель смотрит, о чём ребёнок общался с AI.

### Структура:
- Заголовок: «Чат-отчёт — {Имя ребёнка}»

**Блок статистики (3 карточки):**
- Сообщений за неделю: число
- Любимый персонаж: аватар + имя
- Топ темы: 3 тега (например: «космос», «динозавры», «математика»)

**Список разговоров:**
- Карточки по дням, от новых к старым
- Каждая карточка: дата + персонаж + краткое содержание (автосаммари от AI)
- По клику: раскрывается полный диалог (read-only)
- Если диалог пустой / не было чатов: «Ребёнок пока не общался с персонажами»

### Визуальный стиль:
- Стиль родительского кабинета kidion.ru (Inter, не Nunito)
- Карточки с мягкой тенью, без детских элементов

## Страница 6: Генерация картинки (в чате)

**Контекст:** Ребёнок просит персонажа что-то нарисовать. Персонаж генерирует картинку (Gemini).

### UX-флоу:
1. Ребёнок пишет: «Нарисуй дракона на облаке»
2. Персонаж отвечает текстом: «Отличная идея! Рисую...» + индикатор генерации
3. Появляется картинка в сообщении (до 300px ширина, скруглённые углы)
4. Под картинкой: кнопка «Скачать» (маленькая, текстовая)

### Индикатор генерации картинки:
- Пузырь сообщения с анимацией: карандаш рисует (или кисть)
- Текст: «Рисую...» (пульсирующий)
- Длительность: 5-15 секунд

## Общие принципы дизайна

### Цветовая палитра:
- Основной фон: белый (#FFFFFF)
- Вторичный фон: лавандовый (#F8F6FF)
- Акцентный (Спарк): оранжевый (#FF8C42)
- Сообщения ребёнка: зелёный (#22C55E)
- Текст: тёмно-фиолетовый (#2A2452)
- Текст вторичный: (#6B6791)
- Разделители: rgba(42,36,82,0.08)

### Типографика:
- Заголовки: Baloo 2, 800 weight
- Основной текст: Nunito, 600-700 weight
- Размеры: 14px (сообщения), 17px (имена), 11px (время, лимиты)

### Скругления:
- Карточки: 16px
- Кнопки-пилюли: 999px
- Аватары: 50% (круг)
- Сообщения: 16px (6px на ближнем к отправителю углу)

### Анимации:
- Появление сообщений: fade-in + slide-up (0.25s)
- Typing dots: bounce (1.2s loop)
- Кнопки: translateY(-1px) on hover, translateY(2px) on active
- Переходы между страницами: fade (0.2s)

### Mobile-first:
- Max-width чата: 600px (центрирование на десктопе)
- Tab bar: виден только на мобильном (<900px)
- Safe area insets для iPhone (env(safe-area-inset-bottom))
- Touch-friendly: все кнопки min 36x36px

### Доступность:
- Крупный текст (min 14px для контента)
- Высокий контраст (тёмный текст на светлом фоне)
- Все интерактивные элементы с hover/active состояниями
- Placeholder в инпуте: видимый, но приглушённый
